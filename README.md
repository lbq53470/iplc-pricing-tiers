## IPLC专线为什么从一百多到上万元都有

数量级的差距，主要来自计费方式。

**按带宽计费**的独享专线按“Mbps/月”收费。开发者社区的讨论给出的参考行情是：沪港、广港、深港方向一手独享带宽约20-30元/Mbps/月，照此推算100Mbps独享就是每月两三千元起步。运营商级的MSTP专线更贵——同一场讨论里，深圳联通到香港10M的月费报价1.2万元。腾讯AIA、阿里CEN、华为IPLC这类大厂产品官网标价更高，一部分资源会经代理商以低一些的价格流出。

**按流量计费**的套餐结构完全不同：端口通常给到150Mbps以上，限制的是每月流量额度。IPLC产品的行业惯例约1元/GB，而且普遍按上下行双向计费——这点很多介绍文章不写明，但它直接决定你实际能用掉多少流量。

第三个变量是转售层级。一手资源最贵；一条大带宽专线被切成小份、转手几次之后，价格可以压得很低，代价是超卖和晚高峰掉速的风险都集中在这一层。那场讨论里的一条经验是：200元预算想拿50Mbps“独享”IPLC，基本只能买到转了好几手的货。

顺带一提，线路方向本身也影响价格。除了中港，常见方向还有沪日、沪韩、深新、沪美；越冷门的方向商家越少，比如沪韩、深台，价格通常更高。

## 按带宽还是按流量？算一笔账

结论先给：月流量在几TB以内、不是全天跑满的，流量计费套餐几乎总是更便宜；只有7×24小时跑满带宽、不计量的大流量业务，才值得回到按带宽计费的独享专线。

## 几个高频问题

**IPLC专线个人用，一个月最低要多少钱？**
走合规商家套餐，一百多元就能起步：MKCloud的IXP-2TB月付¥158（IXP线路近期有IXCLOUD优惠码，2TB档6.9折后约¥109），最便宜的纯专线是沪美IPLC-100GB，¥180/月。运营商级独享专线从每月数千元起，个人场景没必要。

**IPLC和IEPL哪个贵？**
同方向下IEPL通常更便宜。IEPL走电信运营商内部的专用网络，绕开公网拥堵；IPLC是点对点私有线路，理论上更稳但成本更高。实际使用中两者体验接近，商家套餐里IEPL往往是性价比更高的那个。

**几十块钱的IPLC套餐是什么？**
通常是把一条大带宽专线切成很多份转售的共享产品，也有商家把多条线路做负载均衡后按流量卖。便宜是真的，但超卖与否完全看商家自觉，晚高峰掉速、节点失联都发生在这一层。真要独享带宽，就得回到按Mbps计费的行情价。

**套餐表里的延迟是什么口径？**
是入口到出口的端到端延迟，比如广港IEPL标称3ms指广州入口到香港出口。第三方实测深圳ping在2-4ms，与标称基本一致；沪日25ms、沪美124ms同理。
